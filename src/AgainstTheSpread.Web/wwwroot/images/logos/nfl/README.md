# NFL team badges

These 32 SVG badges are original project assets. Each badge contains only the
canonical three-character team identifier and its corresponding brand-color
pair; it does not reproduce an NFL or club logo, wordmark, or other licensed
club artwork.

The badge layout was created for Against the Spread and may be redistributed
with this project. Brand-color values are factual identifiers, not artwork.
This approach keeps the application self-contained while avoiding third-party
logo licensing restrictions.

The JSON mapping keys are the canonical uppercase IDs agreed with the backend:
`ARI`, `ATL`, `BAL`, `BUF`, `CAR`, `CHI`, `CIN`, `CLE`, `DAL`, `DEN`, `DET`,
`GB`, `HOU`, `IND`, `JAX`, `KC`, `LAC`, `LAR`, `LV`, `MIA`, `MIN`, `NE`, `NO`,
`NYG`, `NYJ`, `PHI`, `PIT`, `SEA`, `SF`, `TB`, `TEN`, and `WAS`.
